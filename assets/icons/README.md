# Ícones locais

Os 31 SVGs desta pasta foram obtidos da [API do Iconify](https://iconify.design/docs/api/) em 27/09/2026 e são usados como máscaras CSS com a cor da interface. `scripts/vendor-icons.mjs` permite atualizar os arquivos quando houver acesso à internet; isso não é necessário para abrir o design system.

- `solar/`: [Solar, por 480 Design](https://www.figma.com/community/file/1166831539721848736), licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- `mdi/`: [Material Design Icons, por Pictogrammers](https://github.com/Templarian/MaterialDesign), licença Apache 2.0. Consulte [a licença da coleção](Material-Design-Icons-LICENSE.txt) e [o texto Apache 2.0](Apache-2.0.txt).
- `simple-icons/`: [Simple Icons, por Simple Icons Collaborators](https://github.com/simple-icons/simple-icons), licença [CC0 1.0](Simple-Icons-LICENSE.md). Os nomes e marcas retratados podem ter direitos próprios.
